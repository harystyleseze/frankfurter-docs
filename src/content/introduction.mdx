## What Frankfurter does

Frankfurter collects the reference rates that central banks publish every day, stores the full
history, and blends them into one mid-market rate per currency pair. You query it over plain HTTPS
and get JSON, CSV, or NDJSON back. The data starts in 1999 for most currencies, including the
Nigerian naira.

| Fact | Value |
|---|---|
| Base URL | `https://api.frankfurter.dev/v2` |
| Authentication | None |
| Quotas | None. Requests are rate-limited only to prevent abuse. |
| Currencies | 165 active, 223 including legacy codes |
| Sources | 105 central banks and official providers, including the Central Bank of Nigeria (`CBN`) and the European Central Bank (`ECB`) |
| Formats | JSON (default), CSV, NDJSON |
| Updates | Daily, as each provider publishes |
| License | MIT, self-hostable with Docker |

## Who these docs are for

- **Fintech and remittance developers** who need a dependable mid-market rate for pricing,
  reconciliation, or display, without paying for a commercial feed.
- **Analysts and data engineers** who want years of daily history as CSV or a time series.
- **Students and hobbyists** building a currency converter, a dashboard, or a bot.

You need nothing more than `curl` or a language that can make an HTTPS request.

## How a blended rate works

Several providers can publish a rate for the same pair on the same day, and they rarely agree to
the last digit. Frankfurter converts each provider's observation into the pair you asked for,
discards outliers, and returns the blend. Add `expand=providers` to any rates request to see every
contributing observation, or query one provider directly when you need an official figure such as
the CBN rate. The [historical rates guide](/guides/historical-rates#compare-the-blend-with-one-provider)
shows both.
